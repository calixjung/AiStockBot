# 장기 운영 방향: AI에 얼마나 기대고, 어떤 AI를 쓸까

작성 2026-11-15. 가격과 무료 범위는 이날 각 회사 공식 페이지에서 확인했습니다(출처는 맨 아래). 가격은 자주 바뀌므로 결제 전에 다시 확인하세요.

## 질문

> 다 만들고 나면 계속 AI의 도움을 받아야 할지, 그 프로그램 자체로 그냥 돌리는 형태가 나을지. AI 도움을 계속 받아야 한다면 누구 도움이 나을까. 난 무료인 딥시크가 나을 것 같은데.

## 한 줄 답

**매일 매매는 프로그램 혼자 돌리는 것이 기본입니다.** AI는 (1) 봇 안에서 후보 종목 소셜 글을 요약하고 "매수 보류" 신호만 줄 수 있는 보조 역할, (2) 사람이 주 1회쯤 결과를 보고 코드를 고칠 때 쓰는 개발 도우미, 이 두 자리에만 씁니다. AI가 매수 여부를 직접 결정하게 만들지 않습니다.

## "AI"는 두 가지로 나눠서 생각해야 합니다

| | (a) 봇이 실행 중에 부르는 AI | (b) 사람이 쓰는 개발 도우미 AI |
|---|---|---|
| 예 | DeepSeek API로 X·Reddit 글 요약, 루머 판단 | Claude Code, ChatGPT(Codex), Gemini 채팅 |
| 언제 | 장중, 매수 신호가 날 때마다 자동으로 | 사람이 원할 때(코드 수정, 결과 해석, 버그) |
| 연결 방식 | API 키 + 사용량만큼 요금 | 웹 채팅 또는 월 구독 |
| 없으면? | 소셜 검토만 빠지고 봇은 그대로 돈다 | 코드를 고치기 어려워진다(봇은 그대로 돈다) |

어느 쪽이 없어도 봇은 멈추지 않도록 지금 구조가 이미 그렇게 짜여 있습니다.

## 지금 봇은 어떻게 판단하나 (이 저장소 기준)

매수·매도 판단은 전부 **규칙 기반 코드**입니다. AI는 들어가 있지 않습니다.

- 종목 찾기: `bot.py`의 `Scanner` — 15분 거래량이 이전 거래일 같은 시간대의 3배, 가격 범위 0.5% 이하, 거래대금 100만 달러 이상이면 횡보로 보고, 10분 안에 두 분봉 연속 상단 위 마감이면 신호. `orb.py`의 `OpeningRangeScanner`는 개장 5분 범위 돌파.
- 매수 압력: `pressure.py` — 매수 주도 체결대금 70% 이상 등.
- 매수 막기: `PaperBot.veto` — 호가 이상, 스프레드 0.3% 초과, 일일 손실 1% 한도, 시장 거부권(`Market.buy_veto`: SPY·QQQ가 VWAP 아래이고 종목 70% 이상 하락).
- 청산: 상단 아래 마감 또는 30분 보유.
- AI가 들어갈 자리: `SocialReviewer.review()` **하나뿐**입니다. 지금은 아무것도 하지 않고 `None`을 돌려주며, 이때 봇은 `social_unavailable` 로그만 남기고 그대로 진행합니다. 결과가 `flagged=True`이면 그 종목 신규 매수만 막습니다(`social_risk`). 즉 **AI는 매수를 막을 수만 있고, 사게 만들 수는 없습니다.** 이 구조를 유지하길 권합니다.

## 권고 1: 매일 매매는 프로그램 단독 실행

이유를 초보자 눈높이로 정리하면:

1. **재현이 됩니다.** 같은 데이터를 넣으면 같은 결과가 나와야 "이 전략이 좋은가"를 따질 수 있습니다. AI 답은 같은 질문에도 매번 조금씩 다르고, 회사가 모델을 바꾸면 행동도 바뀝니다. 과거 시험(`historical.py`)으로 검증한 규칙과 실제로 도는 규칙이 같아야 합니다.
2. **멈추지 않습니다.** AI 서비스는 장애·지연·요금 한도 초과가 생깁니다. 돌파 신호는 1~2분 안에 처리해야 하는데, 응답을 기다리다 진입 기회를 놓치거나, 응답이 이상해서 봇이 엉뚱하게 움직이면 안 됩니다.
3. **비용이 0입니다.** 규칙 코드는 몇 번을 돌려도 무료입니다.
4. **아직 AI가 고칠 "좋은 전략"이 없습니다.** 2019년 실제 7일 시험(README "2019년 7일 실제 결과") 결과:
   - 거래량 돌파 4건 -$17.94, ORB 5건 -$22.56, ORB+시장 거부권 4건 -$11.46, 매수 압력 전략은 0건.
   - 전략당 거래가 5건 이하라 어느 전략이 낫다고 말할 수 없습니다.
   - 이 상태에서 AI를 더 붙이면 무엇 때문에 결과가 바뀌었는지 더 알기 어려워집니다. 먼저 규칙 전략을 더 많은 날짜로 검증하는 것이 순서입니다.

## 권고 2: AI는 이 세 곳에만, 제한적으로

1. **소셜 글 요약·루머 경고 (봇 안, 선택 사항)**
   - 대상: 매수 신호가 난 후보 종목만. 하루 수십 번 이하로 부르게 됩니다.
   - 역할: "공식 확인 없는 루머가 퍼지는 중" 같은 경고 → `flagged=True`로 신규 매수 보류만. 매수 신호 생성·수량 결정·청산에는 쓰지 않습니다.
   - 시간 제한: 응답을 예를 들어 3초까지만 기다리고, 넘거나 오류면 "검토 불가"로 기록하고 규칙대로 진행(지금 `None` 처리와 같음).
   - 기록: 질문·답·출처 링크를 저장해서 나중에 "AI 경고가 손실을 줄였나"를 과거 시험처럼 따져 봅니다. 효과가 없으면 끕니다.
2. **결과 해석 (사람, 주 1회)** — 대시보드·로그를 붙여 넣고 "어떤 거래가 왜 손실이었나" 물어보기.
3. **코드 수정 (사람, 필요할 때)** — 새 조건 추가, 버그 수정. 고친 뒤에는 반드시 과거 시험을 다시 돌려 숫자로 확인합니다.

## 권고 3: 실제 비용은 AI보다 "데이터"에서 나옵니다

소셜 분석 비용을 대략 계산해 보면(가정: 하루 후보 20번 × 질문당 입력 5,000토큰·출력 500토큰 = 하루 입력 10만·출력 1만 토큰):

| 항목 | 하루 | 한 달(21거래일) |
|---|---|---|
| DeepSeek `deepseek-flash` (미국 장 시간은 할인 시간대) | 약 $0.02 | 약 $0.5 |
| Claude Haiku 5.5 | 약 $0.015 | 약 $0.3 |
| Gemini 무료 등급 | $0 (한도 안) | $0 |
| **X API로 글 읽기**: 후보당 50개 × 20번 = 1,000개 × $0.005 | **약 $5** | **약 $100** |

- AI 요약 비용은 어느 회사를 써도 한 달 1달러 안팎입니다. "딥시크가 무료라서"는 결정적 차이가 아닙니다.
- 진짜 돈이 드는 곳은 X 글을 가져오는 비용입니다(X API는 글 1개 읽을 때마다 $0.005, 무료 검색 등급 없음). Reddit API 조건은 이번에 확인하지 않았습니다.
- DeepSeek 할인 시간: 평일 01:00~04:00, 06:00~10:00 UTC가 정상가, 나머지는 반값입니다. 미국 정규장(한국 시간 밤 11:30~새벽 6:00, 서머타임 해제 기준)은 UTC 14:30~21:00이라 할인 시간에 해당합니다.

## AI 선택 비교

### "딥시크가 무료라 낫다"에 대해

맞는 부분:
- 웹 채팅은 무료이고, API도 매우 쌉니다(`deepseek-flash` 100만 토큰당 입력 $0.15·출력 $0.60, 할인 시간 기준). 이 용도라면 한 달 1달러도 안 됩니다.
- 원래 계획(`CLAUDE-PROMPT.md`)에서도 소셜 분석에 DeepSeek를 쓰기로 했고, 글 요약 정도는 충분히 해냅니다.

주의할 부분:
- **봇이 부르는 것은 무료 웹 채팅이 아니라 유료 API입니다.** 충전(결제)과 API 키 발급이 필요합니다. 웹 채팅을 자동으로 긁어 쓰는 방식은 약관 위반 소지가 있고 쉽게 깨집니다.
- **데이터가 중국 서버에 저장됩니다.** 개인정보처리방침에 서버가 중국에 있다고 적혀 있고, 입력을 모델 개선에 쓸 수 있습니다(설정에서 끌 수 있음). 공개된 X·Reddit 글과 종목 이름만 보내면 큰 문제는 아니지만, 계좌 정보·회사 자료·API 키는 절대 넣지 않습니다. 회사 PC에서 쓴다면 회사 보안 규정도 확인하세요.
- **실시간 정보를 스스로 찾지 못합니다.** API는 우리가 넣어 준 글만 읽고 판단합니다. "오늘 이 종목에 무슨 일이 있었나"를 알아서 검색해 주지 않으므로 글 수집은 우리 코드가 해야 합니다(이건 다른 회사 API도 기본적으로 같습니다).
- **안정성:** 사용자가 몰릴 때 느려지거나 오류가 나는 일이 있을 수 있으니, 위의 시간 제한·실패 시 무시 구조가 필수입니다. 어느 회사든 같은 대비가 필요합니다.
- **개발 도우미로는 약합니다.** DeepSeek 웹 채팅은 이 폴더 파일을 직접 읽고 고치고 시험을 돌리지 못합니다. 코드를 복사·붙여넣기 해야 하고, 어디가 바뀌었는지 사람이 맞춰야 합니다. 코딩이 처음인 분에게는 이 부분 부담이 큽니다.

### 추천

**(a) 봇 안의 소셜 분석용**
1. 1순위: **DeepSeek API(`deepseek-flash`)** — 원래 계획대로. 공개 글만 보내므로 중국 서버 문제는 감수 가능하고, 비용은 월 1달러 미만. 단, 충전·키 발급은 사용자 결정 사항입니다.
2. 무료로 먼저 시험해 보고 싶으면: **Gemini API 무료 등급** — 결제 없이 키만 받아 시험 가능. 무료 등급 입력은 구글이 활용하지만 공개 글이라 괜찮습니다. 한도를 넘으면 오류가 나므로 "실패 시 무시" 구조로.
3. 완전 무료·오프라인을 원하면: **Ollama 로컬 모델** — 이 PC에서 가능은 하지만 장중에 PC를 켜 둬야 하고 응답이 느릴 수 있습니다.
- 어느 것을 고르든 `SocialReviewer`를 상속한 클래스 하나만 바꾸면 되도록 만들면 나중에 갈아타기 쉽습니다.

**(b) 개발 도우미용**
- 지금처럼 **Claude Code**(또는 같은 방식의 ChatGPT Codex)를 권합니다. 파일을 직접 읽고, 고치고, 과거 시험을 돌려 숫자로 확인하고, 커밋까지 해 주므로 코딩이 처음인 분에게 복사·붙여넣기 방식보다 실수가 훨씬 적습니다. 월 $20 정도 비용이 들지만, 매일 쓸 필요는 없고 개선 작업을 몰아서 하는 달만 구독해도 됩니다.
- 비용을 0으로 하고 싶다면 DeepSeek·Gemini 웹 채팅에 질문하는 것도 가능하지만, 이 경우 수정 후 `python dashboard.py --historical ...`를 직접 돌려 결과가 바뀌지 않았는지 확인하는 습관이 꼭 필요합니다.

## 정리: 단계별 운영 모습

1. **지금~실시간 모의매매 시작:** AI 없이 규칙 봇만. 개발은 Claude Code로.
2. **실시간 모의매매 몇 주:** 하루 결과를 자동 기록. 주 1회 AI에게 결과 해석을 물어보고, 바꿀 점은 과거 시험으로 확인한 뒤 반영.
3. **소셜 검토 추가(선택):** 후보 종목만, 매수 보류 신호만, 시간 제한·실패 시 무시. DeepSeek 또는 Gemini 무료 등급. X API 비용(월 약 $100 추정)이 먼저 결정할 문제.
4. **소셜 경고의 효과 점검:** 경고로 피한 손실과 놓친 수익을 비교해 효과가 없으면 끕니다.
5. 실전 주문은 별도 결정 사항입니다(현재 미래에셋 개인 계좌 미국주식 주문 API 미확인).
