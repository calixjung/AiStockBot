# 미국주식 모의매매 봇

Python 3.10 이상에서 압축을 풀고 해당 폴더에서 실행합니다. 외부 패키지와 API 키 없이 실행됩니다.

```powershell
python demo.py
```

- `bot.py`에는 종목 스캐너, 시장·위험 거부권, 소셜 검토 인터페이스, 모의 체결이 들어 있습니다.
- `demo.py`는 합성 시세로 돌파만, 시장 거부권 추가, 소셜 검토 추가를 나란히 실행합니다. 신규 매수 보류, 매수·청산, 손익·최대 낙폭을 출력합니다.
- 예제 임계값은 거래량 3배, 15분 가격 범위 0.5%, 15분 거래대금 약 100만 달러, 최대 스프레드 0.3%, 일일 손실 한도 1%입니다. 모두 초기 검증값입니다.
- 시장 상태와 상대 거래량은 입력으로 주어집니다. 실제 데이터 연결 시 거래일별 정규장 분봉·호가, 시간대별 과거 거래량, 시장 지표를 공급해야 합니다.
- 소셜 검토 입력이 없으면 로그를 남깁니다. 예제에서는 합성 루머가 발견된 경우에 매수를 막습니다.
- 예제 손익은 가상의 가격과 비용을 사용한 동작 점검 결과입니다. 실제 시세·증권사·X·Reddit·AI API는 연결되지 않았습니다. 공개 장초반 돌파 전략은 별도 비교 구현이 필요합니다.

## 매수 압력에도 가격이 제자리인 경우

`python pressure.py`로 가상 체결 집계 예제를 실행합니다. 같은 시간대의 평소 분류 가능 거래대금 대비 3배 이상, 매수 주도 체결대금 비중 70% 이상, 매수·매도 중간 호가의 고저 범위 0.5% 이하를 초기 관찰 조건으로 둡니다. 거래 주체의 신원을 추정하거나 매수 주문을 내는 기능은 없습니다. 체결 방향을 제공하는 피드 또는 시각이 맞춰진 체결·호가로 만든 집계가 필요합니다. 이 감지기는 기본 돌파 데모와 별도로 실행됩니다.

## Windows에서 대시보드 열기

1. ZIP 전체를 한 폴더에 압축 해제합니다.
2. `open-dashboard.bat`를 더블클릭합니다. Python 3.10 이상이 필요합니다.
3. 실행할 때마다 `dashboard.py`가 `demo.py`와 `bot.py`를 실행하고 결과를 `trading-dashboard.html`에 넣어 브라우저로 엽니다.

PowerShell에서는 압축을 푼 폴더에서 `python dashboard.py`를 실행해도 됩니다. 저장한 X·Reddit 글은 예시입니다.

`위원회 + 매수 압력` 전략은 가상 체결 집계로 매수 압력 조건을 확인한 뒤 돌파를 기다립니다. 기존 `분석위원회`와 비교할 수 있습니다. 실제 체결 데이터는 연결 전입니다.

## 공개 과거 데이터 시험

LOBSTER의 AAPL 2012-06-21 NASDAQ 레벨 1 샘플에서 메시지와 호가 CSV를 받아 각각 `message.csv`, `orderbook.csv`로 저장하고, 두 파일을 담은 폴더를 지정합니다.

```powershell
python historical.py "C:\path\to\sample"
```

이 시험은 한 거래일뿐이므로 같은 시각의 여러 거래일 평균 대신, 당일 현재 구간과 겹치지 않는 앞선 15분 구간들의 중앙값을 임시 기준으로 사용합니다. 시장·소셜 거부권은 두 전략 모두 적용하지 않습니다. 결과는 체결·호가 입력을 처리하는 점검이며, 전략 평가에는 여러 거래일과 종목이 필요합니다.

샘플 출처 https://data.lobsterdata.com/info/DataSamples.php
샘플 미러 https://huggingface.co/datasets/y7pan/lobster-data

## 여러 거래일 시험

데이터를 `데이터폴더/YYYY-MM-DD/종목/message.csv`와 같은 위치의 `orderbook.csv`로 배치합니다. 두 CSV는 동일한 LOBSTER 레벨 1 기록이어야 합니다.

```powershell
python historical.py "C:\path\to\data"
```

종목별로 이전 거래일의 같은 15분 구간 중앙값을 사용합니다. 첫날은 기준을 쌓습니다. 하루치만 있으면 `--intraday-reference`를 붙여 당일 기준으로 입력 경로를 점검할 수 있습니다. 입력 날짜가 미국 표준시라면 `--utc-offset=-5`를 지정하세요. 이 버전은 한 실행에서 고정 UTC 오프셋을 사용합니다.

공개 샘플 점검(2012-06-21, AAPL·AMZN·GOOG·INTC·MSFT)에서 당일 기준으로 1,520개 구간을 평가했습니다. 상대 거래량 조건 69개, 매수 압력 조건 0개, 양쪽 체결 0건입니다. 같은 시간대 기준 실행에서는 이전 거래일이 없어 평가 구간이 0개였습니다. 기존 대시보드는 가상 시세 리플레이를 표시합니다.

## 과거 결과를 브라우저에서 보기

`historical-dashboard.html`에는 공개 5종목 하루치 샘플을 실행한 결과가 들어 있습니다. 새 데이터를 넣으면 아래 명령으로 대시보드를 다시 생성합니다.

```powershell
python dashboard.py --historical "C:\path\to\data"
```

한 날짜만 있고 당일 비교로 입력을 점검하려면 `--intraday-reference`를 추가합니다. 기본 실행 파일은 기존 가상 시세 대시보드를 엽니다.

## 여러 거래일 원본 확보 (2019년 공개 샘플 7일)

나스닥 공개 샘플 중 ITCH 5.0 전체 하루 파일이 있는 날짜는 2019-01-30, 03-27, 07-30, 08-30, 10-18, 10-30, 12-30이며 파일당 3.5~5.5 GB(총 약 25 GB)입니다. 실측 다운로드 속도는 1.7~5.7 MB/s였습니다. 두 스크립트는 Git Bash에서 실행하며, 원본은 `D:\us-stock-data\itch`, 추출 결과는 `D:\us-stock-data\sessions`(거래 대상 10종목)와 `D:\us-stock-data\index`(SPY·QQQ, 시장 필터용)에 쌓입니다. 다른 드라이브를 쓰려면 두 스크립트 안의 경로를 바꿉니다. 다운로드는 중단 후 다시 실행하면 이어받고 md5로 검증합니다.

```bash
sh scripts/download-itch.sh
```

```bash
sh scripts/extract-itch.sh
```

두 스크립트를 동시에 띄워 두면 검증이 끝난 파일부터 추출합니다. 하루 추출은 순수 Python이라 15~20분쯤 걸립니다. 추출이 끝나면 아래 명령으로 비교와 대시보드를 만듭니다. 첫 날짜는 기준만 쌓고 나머지 6일을 평가합니다.

```powershell
python dashboard.py --historical "D:\us-stock-data\sessions" --utc-offset=-5 --no-open
```

결과의 `filter_avoided_loss`·`filter_missed_profit`는 돌파 전략이 체결했지만 매수 압력 전략은 거른 거래의 손실 합과 이익 합입니다. 날짜가 표준시·서머타임에 걸쳐 있지만 ITCH 시각은 거래소 현지시간이라 화면 표시는 영향이 없습니다.

## 나스닥 ITCH 원본에서 종목 추출

공식 샘플 https://emi.nasdaq.com/ITCH/Nasdaq%20ITCH/ 에서 받은 ITCH 5.0 gzip 파일을 지정합니다. 날짜별로 반복하고 같은 출력 폴더를 사용합니다. 완성된 날짜 폴더가 이미 있으면 덮어쓰지 않습니다.

```powershell
python itch_extract.py "C:\data\12302019.NASDAQ_ITCH50.gz" "C:\data\sessions" 2019-12-30 AAPL AMZN GOOG INTC MSFT
python dashboard.py --historical "C:\data\sessions" --utc-offset=-5
```

추출기는 주문 추가·취소·체결·교체를 따라 나스닥의 최우선 매수·매도 호가를 재구성합니다. 표시 주문 체결은 반대편을 주도 방향으로 집계합니다. 방향 미상의 비표시 체결은 전체 거래량에 들어가며 매수·매도 주도 비중 계산에서는 빠집니다. 경매와 사후 체결 취소는 이 버전에서 반영하지 않습니다. 장 마감 이벤트 전에 끝난 입력은 완료된 날짜로 저장하지 않습니다.
